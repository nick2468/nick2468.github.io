Tabiya teaches chess opening repertoires by explaining them. A tabiya is the standard
position an opening heads for, before the game goes its own way.

Ten courses come with the app, five as White and five as Black, in 71 chapters. Every move
carries a note saying why it is played, and every line ends with a plan. You study a line,
drill it back from memory on a schedule, then play it against an engine that is steered
into the lines you have studied.

A checker plays every line the notes name on a real board. That is how a note that
recommends an illegal move gets caught before anyone trusts it.

The installer is signed with a code signing certificate, so Windows names the publisher
as Open Source Developer Nicholas Walker. Windows SmartScreen may still warn about a new
release for a while, until it builds up a reputation.
